# SmileSchool Landing Page

This is a responsive landing page built with HTML and CSS, based on a Figma design provided by the school for the HTML Advanced project.

## Features

- Hero section with call-to-action
- Testimonials and tutorial cards
- FAQ and footer with social links
- Responsive layout using custom styling

## How to Use

1. Open `index.html` in a browser.
2. Add your styles in `styles.css`.
3. Place all images in the `/images` folder.

## Fonts

- [Source Sans Pro](https://fonts.google.com/specimen/Source+Sans+Pro)
- Spin Cycle OT (if provided)

## Design Reference

Duplicate the provided Figma file to your Drafts to inspect spacing, fonts, and layout.
